# Results

All numbers below are generated by `python -m isaagent.report` from `results/episodes.jsonl`, `results/baselines.json` and `results/mlir_flow.json`. Nothing is typed in by hand.

Setup: 14 DSP kernels x 3 seeds per condition, local models served by Ollama on one NVIDIA L4 (temperature 0.4). Programs are compiled with clang 18 for RV64GCV and run on QEMU 8.2 (VLEN = 128). "Pass" = bit-exact (integer) or within tolerance (float) on every test case, including edge sizes and a forced-saturation case, with no writes past the output buffer. Brackets: Wilson 95% interval. Costs are dynamic instruction counts inside the kernel on QEMU, NOT cycles.
